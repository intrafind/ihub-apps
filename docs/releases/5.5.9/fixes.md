# Fixes — 5.5.9

## Outlook Add-in: Chat Input No Longer Overhangs Its Column

The chat input on the Outlook add-in's start page and its per-app chat view stretched edge-to-edge
across the pane, wider than the app name row, starter prompts, and app shortcuts around it, which
all sit indented from the pane's edges.

- The chat input now shares the same indent as the rest of the pane, so it lines up with the other
  controls instead of looking oversized.
