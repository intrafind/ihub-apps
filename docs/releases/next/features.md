# Features — Unreleased

## Projects: iFinder Documents Open, Preview and Show Details Like Chat Sources

An iFinder document in a project now offers what a cited iFinder document offers in a chat:
**Open in iFinder**, and under **More actions** **Preview (PDF)**, **Download** and **Details**
(file, author, path). Everyone who may read the project gets them, in user and admin projects and in
smart collections, always with their own iFinder rights.

The iFinder document and search pickers of **Add documents** have **Search in**: the user's search
profiles, the same list the chat input offers. A document found in another profile is read in that
profile later.

## Projects: Default App for Project Chats

Full administrators can set the app project chats start in under **Admin → Projects → Project
settings → Default app for project chats** (`platform.projects.defaultAppId`). A project's own
default app still comes first; without one, chats now start in this app instead of the first app in
the list.
