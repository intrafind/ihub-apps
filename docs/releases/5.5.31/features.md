# Features — 5.5.31

## Marketplace: License Links

The license in a marketplace item's detail panel is now a link to the full license text when the
registry provides one, so admins can check the terms before installing.

- Registries add the link with the new optional `licenseUrl` field on each catalog item.
- The iHub Official Marketplace links every item to its license, the BSD 3-Clause License with
  Mandatory Attribution. Refresh the registry under **Admin → Marketplace → Manage Registries** to
  see the links.
