# iHub Apps Documentation

iHub Apps is a platform for AI applications in your organization: you connect language models,
build apps, workflows and agents on top of them, connect them to your own systems, and decide who
may use what. This documentation explains how to install, configure and run iHub, and how users
work with it. If you are new to iHub, read [Core Concepts](concepts.md) first.

## Start here

- [Getting Started](GETTING_STARTED.md) — Start iHub for the first time and sign in as admin.
- [Models](models.md) — Connect a language model and choose which models apps may use.
- [Apps](apps.md) — Build your first app: its prompt, model, tools and who may use it.
- [Authentication Quick Start](AUTHENTICATION_QUICK_START.md) — Set up how users sign in.
- [Integrations](integrations.md) — Connect iHub to your document stores and business systems.
- [Reverse Proxy Deployment](production-reverse-proxy-guide.md) — Run iHub in production behind a reverse proxy.
