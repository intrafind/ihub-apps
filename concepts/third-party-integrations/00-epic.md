## Summary

Apps get much more useful when they can work where our users' information lives: mailbox, calendar, Teams, SharePoint, Confluence, Jira, the service desk, the CRM, databases. Today iHub has:

- **Jira** (Cloud only): search, read, comment and transition as model tools;
- **Office 365, Google Drive and Nextcloud**: a manual file picker only;
- **Entra people search** (app-only);
- **iFinder / iAssistant**;
- the generic **OpenAPI tool runner** (#1462).

This epic collects the integrations we want to add, on top of one shared connection framework.

MCP servers are a separate track and not part of this epic.

## Principles

- **Delegated by default.** The model acts with the signed-in user's permissions in the external system (per-user OAuth). Shared admin credentials only where the service has no per-user auth, or where the admin wants that on purpose.
- **Writes need a human.** Anything that sends, creates, updates or deletes goes through a confirmation card with the exact payload, unless the admin explicitly relaxes this per connector.
- **External content is untrusted.** Emails, tickets, pages and messages can contain instructions aimed at the model. They never trigger an action by themselves.
- **Admin-controlled.** Admins enable each connector per group, request only the scopes of the enabled capabilities, and can revoke connections.
- **One contract per domain.** Mail, calendar, tasks, CRM and files use the same tool shapes across providers, so apps can work with any provider.
