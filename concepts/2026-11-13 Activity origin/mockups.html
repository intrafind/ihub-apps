1. The problem run (F1, the screenshot)

The same run three ways. Hit titles, hosts, word counts and queries are the real strings from the screenshot; the answer line is German because the answer was. The proposed collapsed line is identical in Option C and in A-prime; only the expanded list differs.

2. Single origin, the common case (F6)

One web search, five hits. The proposal adds no header line and removes the argument chips; the switch row appears only when a row has technical details and the turn is finished (it is shown here in section 6).

3. Zero hits then web fallback (F5), and the agentic run (F3)

F5: the project search finds nothing, the model goes to the web; segments are in first-use order. F3: iFinder, two Jira calls, a Munich AD people search and a created PDF; only two origin segments are named, the rest is +N, the output is always shown.

4. Streaming filmstrip (F4)

The list is open for every user while the answer streams, so stability matters for everyone: rows only append or change their own text. Five frames from UX brief section 3.3, EN, then reduced motion and German at 320 px.

5. Skill chip: one home, always with who

A status, not a control: tinted, no border, no focus stop, no tooltip. The reason is person-neutral text. The glyph is academic-cap; sparkles stays with the footer's AI segment.

6. Technical details: off and on

The switch sits directly under the headline, only on a finished turn with an open list and at least one row with details. Off is the default. Click either switch to toggle it.

7. Sources panel: origin on every card

Side panel, about 384 px. The origin noun is the first token of every card's meta line, as text only: the card's leading glyph already says page, file or item. A project document and an iFinder document differ by noun and by what follows it (project name and “Uploaded” versus the search-profile chip). The mixed-origin summary sits directly under the title.

8. German at 320 px

The Outlook task pane width with German strings (about 30 % longer). Segments wrap at their boundaries, facts wrap at fact boundaries (the separator dot trails the line, it never starts one), hit titles clamp at two lines and the host drops below them.
