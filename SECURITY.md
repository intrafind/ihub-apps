# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities privately, not through a public GitHub issue.

**Contact:** [security@intrafind.com](mailto:security@intrafind.com)

Include as much detail as you can: the affected version or commit, steps to reproduce, and the
potential impact. We'll acknowledge your report and work with you on a fix and a disclosure
timeline.

This address is also used as the `primary_contact` for automated scanning via
[Anthropic's OSS Scanner](https://github.com/anthropics/oss-scanner).

## Security Documentation

For the project's security architecture, automated checks run on every pull request, and how to
handle findings, see [`docs/security.md`](docs/security.md).
