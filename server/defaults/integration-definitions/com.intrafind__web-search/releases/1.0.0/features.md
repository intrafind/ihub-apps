# Web search 1.0.0

- First version of the built-in web search definition. The installation `websearch` holds the default search engine and the credential references of Brave and STAAN.
- Four actions keep their tool ids: `braveSearch`, `staanSearch`, `qwantSearch` and `read_url`.
- Apps keep their `websearch` settings (enabled, enabled by default, engine); the installation is a requirement of every app that has web search on.
