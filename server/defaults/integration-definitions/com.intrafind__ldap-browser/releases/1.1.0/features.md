# LDAP browser 1.1.0

- The definition ships the **LDAP browser** app as an example app (`apps/ldap-browser.json`).
  On the page of an installation, **Test in chat** creates it bound to that installation with one
  click and runs it in a chat panel beside the page.
- No change to the settings or the actions; installations move to 1.1.0 without a migration.
