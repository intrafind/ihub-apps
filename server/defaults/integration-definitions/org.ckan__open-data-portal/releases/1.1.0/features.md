# CKAN Open Data Portal 1.1.0

- The definition ships the **Open Data Assistant** as an example app
  (`apps/open-data-assistant.json`): it searches datasets, reads their metadata and queries
  DataStore tables, and links every dataset it names. On the page of an installation,
  **Test in chat** creates it bound to that installation with one click and runs it in a chat
  panel beside the page.
- No change to the settings or the actions; installations move to 1.1.0 without a migration.
