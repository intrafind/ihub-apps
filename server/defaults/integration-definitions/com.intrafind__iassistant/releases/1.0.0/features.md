# iAssistant 1.0.0

- First version of the built-in iAssistant definition. The installation `iassistant` holds what used to live in `platform.iAssistant`: the iFinder installation it runs on (`connection`), the default profile and search profile, grounded-only answers and the search-profile cache.
- The iAssistant model is served through the installation; an app on that model binds it.
